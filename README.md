Описание проекта:
Проект предназначен для выполнения курсовой работы. Включает в себя исходный код, обучающие материалы и документацию.

Структура репозитория
Папка/Файл	Назначение
APP/	Исходный код основного приложения.
ОБУЧЕНИЕ/	Дополнительные материалы и ресурсы для обучения.
.idea/	Служебная папка для конфигураций среды разработки (например, PyCharm).
README.md	Этот файл с описанием проекта.
